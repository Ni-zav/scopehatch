# Market and positioning

## Competitive map
- Generic inference gateways (LiteLLM, Portkey): routing, observability, budgets and provider integrations. We should interoperate rather than copy their complete feature sets.
- Document/proposal products (Proposify, Qwilr): editing, templates, signatures, sales workflows. We should not attempt feature parity in the MVP.
- Automation and agent builders (n8n, Dify, LangGraph ecosystem): broad workflow composition. Scopehatch differentiates on inspectable, version-bound business decisions and domain-specific workpacks.

## Narrow wedge
An agency owner pays for fewer underquoted or forgotten requirements, easier quote review, and repeatable estimates. The gateway underneath is infrastructure, not the purchase rationale.

## Testable hypotheses (not established facts)
H1: a studio repeats this workflow weekly. H2: owner trusts human-edited extraction with links to source text. H3: catalog-based estimates save meaningful review time. H4: BYOK/self-hosting offsets privacy concerns. H5: managed hosting has sufficient willingness to pay.

## Distribution hypothesis
Start with 5–10 user interviews; publish an open-source self-hosting quickstart and truthful technical case study; test a paid managed convenience offering only after users repeat workflows. Avoid implying these are current customers.

## Monetization sketches
Apache-2.0 community core; optional BYOK managed hosting and support. Suggested early experiments: Solo $19–29/month, Studio $59–99/month, Team $149–299/month. These are unvalidated prices. Revenue margin depends on retention, hosting, support, acquisition, and payment costs. No financial forecast follows from API token costs alone.

## Decision
Optimize for proof that teams approve useful workpacks, not number of supported LLMs.
