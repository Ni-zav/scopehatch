# Contributing

Start with README.md, AGENTS.md and docs/03-workflow-and-contracts.md. For code changes, open a focused PR with tests, reproduction steps, and a clear statement of what remains unimplemented. Run `npm test` and `npm run demo`. Keep fake fixtures; never commit customer briefs, private SVEIN data or tokens. Models may propose content but cannot approve or set binding prices. The project is Apache-2.0 licensed; contributions follow that license.
